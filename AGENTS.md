
- Action surface routing (lanes, dedupe, rule checks) lives in pure functions in src/lib/actionSurface.ts with thresholds in src/config/signalRules.ts; UI components only render its output — keeps display rules testable and out of score/IRR-BB maths.
- Portfolio sheets are fetched once by src/data/PortfolioProvider.tsx (React Query) and read via usePortfolio(); each source reports ok/error/empty and panels on a non-ok source render NO DATA — no static fallbacks, so a failed fetch never shows as zero.
- Headline numbers (AUM, cash, gross DP, IRR-BB, asymmetry, band, tier) are read from the sheet via src/lib/canonical.ts; computeIrrBb survives only as a dev-mode cross-check — the app must not diverge from the sheet.
- Tracker automation endpoints share server-only secret authentication and keep v1 REST normalization intact; v2 additions use strict function-local validation and fixed SDK RPC/upsert paths, never generic table/RPC writes, to preserve session contracts and bound service-role access.
- MCP handlers preserve the SDK-verified OAuth subject and bearer through a shared caller-scoped database factory; never use service-role queries for MCP, so table RLS remains the authorization boundary.
- Browser price/earnings endpoints share verified owner-or-ingest authentication and exact app-origin CORS; OAuth client administration independently checks the verified owner before using server credentials.
- Browser portfolio and webhook calls use owner-only sheet-read and n8n-proxy; sheet-read caches Apps Script key batches for 60 seconds and the client adapts values at the existing parser boundary — keeps credentials server-only without changing canonical calculations.
- Portfolio context identity persists in Vite hot data across Fast Refresh — prevents mounted providers and reloaded hooks from referencing different contexts.
- Canonical price-completeness helpers drive holding badges and headline warnings; ingestion retains positive-share rows even at zero MV — missing prices must not disappear before validation.
- Live-price consumers pass sheet currency and share pure symbol/currency safety rules with the edge function; Movers ranking uses tested pure thresholds — prevents foreign-listing quotes and unit mismatches from becoming ranked moves.
- Earnings-engine verdict rows apply through n8n-proxy `apply-tracker`, which loads staged_payload server-side under the caller's session and enforces the cell allowlist in the pure apply-contract.ts shared with vitest — the browser never sends cell writes.
